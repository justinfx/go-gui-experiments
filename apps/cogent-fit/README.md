# GGUIX with Cogent Core

Cogent Core `v0.5.27` implementation of the GGUIX reference app. Module `gguix/apps/cogent`, depends on `gguix/core` through a `replace` to `../../core`.

## Prerequisites

A Mac (Apple Silicon) with Homebrew, the Xcode Command Line Tools (`xcode-select --install`) and Go 1.27.3. Nothing else is needed for the desktop and web targets. Docker is only used for the optional `cross-linux` attempt.

## Bootstrap from a clean machine

```sh
xcode-select --install                 # once, if not present
brew install go                        # or install go1.27.3 from go.dev
export PATH="$PATH:$HOME/go/bin"
cd apps/cogent
make deps                              # go install cogentcore.org/core@v0.5.27 and go mod download
make run                               # build and run the desktop app
```

How the project itself was bootstrapped (Cogent Core has no project template command): the hello-world tutorial (`core.NewBody()`, widgets, `b.RunMainWindow()`), `go mod init gguix/apps/cogent`, `go get cogentcore.org/core@v0.5.27`, `go mod tidy` (tidy is required so that the web-only dependencies get go.sum entries).

## Targets

| Target | What it does |
|---|---|
| `make deps` | Installs the `core` CLI at v0.5.27 and downloads modules. |
| `make dev` | `core run` (rebuild and run; v0.5.27 has no hot reload for desktop). |
| `make build` | `core build`, binary at `bin/gguix-cogent`. |
| `make package` | `core pack`, bundle at `bin/GGUIX-cogent.app` (the `.dmg` step needs `pip install dmgbuild` and is not used). |
| `make run` | Build and run. |
| `make web` | `core build wasm -o bin/web`, then serves it on http://localhost:8090 with the core server's static file mode. |
| `make web-remote` | Same with the `remote` build tag (added through a `go` wrapper script, see `web/gotags-shim.sh`), served by `core/cmd/server` with the real API. |
| `make test` | All automated tests, last line `GGUIX_TESTS passed=<n> failed=<n> not_feasible=<n>`. Tests run in the framework's offscreen window. |
| `make bench` | Desktop bench script (needs a real, unlocked display). |
| `make bench-web` | Serves the web build; open `http://localhost:8090/?bench=1` and watch the browser console. |
| `make cgoprobe` | Rebuilds each target with `-tags cgoprobe` and prints `CGOPROBE <target> PASS\|FAIL <reason>`. |
| `make cross-windows`, `make cross-linux` | Cross-build attempts through the `core` CLI. |
| `make clean` | Removes `bin/` and generated files. |

## Notes

- `GGUIX_ROWS`, `GGUIX_LATENCY_MS`, `GGUIX_EXPORT_RPS`, `GGUIX_PREFS_DIR`, `GGUIX_REMOTE_URL` work as described in the brief.
- Desktop windows need an unlocked macOS session (GLFW finds no screen while the Mac is at the lock screen).
- The app embeds a default `icon.svg` generated by `core pack`.
