# Out-of-box style appeal (Phase 1, blind)

Blinding caveat: every desktop screenshot shows the framework name in the window title bar (for example "GGUIX - Wails"), so the labels were not truly blind. Scores below are based on visual quality only.

| Label | Score |
|---|---|
| A | 5 |
| B | 3 |
| C | 3 |
| D | 4 |
| E | 3 |

**A (5).** Clean neutral shadcn-style look with consistent spacing, aligned form labels, subtle row selection, and well-balanced cards with avatar, rating, and stock bar. Light and dark themes are equally polished, and desktop and web are pixel-consistent. The only nitpick is a truncated SKU column in the table.

**B (3).** Cards and table read well, and the dark theme row highlight is strong. In light mode the form labels are almost invisible (very low contrast), and the Save/Revert buttons render as dark blank blocks. The table cuts off the Stock column, and the toolbar looks heavy. Web and desktop match.

**C (3).** Material look with rounded pills and blue accents. It feels modern but crowded: the table is dense with small text, Status radios are stacked vertically, wasting space, and the rating value is clipped ("3."). Web shots show a stuck "Loading..." status bar, and the table's left column is cramped. Themes are consistent.

**D (4).** Shadcn-like and close to A in polish, with consistent themes and good cards. Small flaws: the Status radios wrap onto two lines, the SKU column truncates, and the status bar is sparse. Overall modern and coherent across desktop and web.

**E (3, desktop only).** Native macOS controls with a correct platform look, but the layout is cramped: form fields are narrow, the Name field clips its text ("eluxe Silicone Lamp"), and there is a large empty right area. Cards are good. The table shows no visible selected-row highlight even though the form shows row 1. Dark and light are both consistent.
